还有问题？提交 Issue ↗
抓包文件会上传到服务器吗？+

桌面版在你的电脑上调用 tshark 解析抓包，分析数据保留在本地。这个首页的交互预览只使用仓库内置的合成示例，不接收或上传你的抓包。

需要安装什么？支持哪些系统？+

桌面版需要 Wireshark 的 tshark 解析器，可在工具中设置路径。项目基于 Tauri，面向 Windows、macOS 和 Linux；各平台现成安装包以 GitHub Releases 实际提供的文件为准。源码构建还需要 Node.js、Rust 及对应平台的构建依赖。

它和 Wireshark 是什么关系？+

pUI 使用 Wireshark 的 tshark 作为解析引擎，专注会话时序、故障事件、双点对照与证据报告。需要深入协议细节时，可以结合 Wireshark 继续检查。

看到重传，就能判断网络丢包吗？+

不能。重传只是观察线索，还可能与延迟、乱序、ACK 未被观察到或抓包遗漏有关。pUI 会保留具体报文证据与观察限制，帮助你验证推断。
